# DarziFlow — Frontend

Frontend application for **DarziFlow** — a garment production management system featuring interactive dashboards, role-based workflows, order tracking, real-time messaging, quality control monitoring, and modern tailwind-styled UI built with React, Vite, and Three.js/GSAP animations.

## 🚀 Features

- **Interactive Dashboards & Analytics**: Tailored interface for Buyers, Manufacturers, Quality Controllers, and HR/Admin roles.
- **Order Tracking & Management**: End-to-end status updates, order creation, and customization handling.
- **Real-Time Messaging**: Built-in chat using Socket.IO and Firebase integrations.
- **Modern UI & 3D Visualizations**: Responsive Tailwind CSS designs, smooth GSAP animations, Lenis smooth scrolling, and Three.js canvas components.
- **Role-Based Workflows**: Custom views and route access control based on user authentication state.

## 🛠️ Tech Stack

- **Framework**: React 19, Vite
- **Styling**: Tailwind CSS, Styled Components, Ant Design
- **Animations & 3D**: Three.js, React Three Fiber/Drei, GSAP, Framer Motion, Lenis
- **State Management & Data**: Zustand, Axios, Socket.IO Client
- **Icons & UI Utilities**: Lucide React, React Icons, Recharts

## 📦 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ZohaibHasan2280168/darziflow-frontend.git
   ```

2. Navigate into the directory:
   ```bash
   cd darziflow-frontend
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Run the development server:
   ```bash
   npm start
   # or
   npm run dev
   ```

5. Build for production:
   ```bash
   npm run build
   ```
